How can I ensure that my code, program, or software is functional and secure?
I can ensure my code is functional and secure by utilizing automated unit and regression testing to make sure the features work. When it comes to security scans I will use the OWASP guidelines and dynamic code analysis tools to catch vulnerabilities early.
How do I interpret user needs and incorporate them into a program?
I interpret user needs when gathering direct feedback by performing usability and conducting interviews. Requests are categorized into functional needs such as what the app does and nonfunctional needs such as speed and security.
How do I approach designing software?
When I approach designing software I take an unbiased approach towards gathering the clients and the users requirements and think about how to appropriately make sure their products desired standards are met when planning and creating the software. The system architecture will be thought of early on such as the data flow being mapped out and the database schemas and system components planned out before writing large amounts of code. Small independent components will designed that way so that a change or failure in one area does not break the system. I will will also ensure that the system fails safely and  defaults to restricted or protected states instead of accessibility remaining open.
